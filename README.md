# 🌐 Sourcing Atlas — US Wholesale Distributor Finder

An AI-powered tool that finds authentic US-based wholesale distributors and suppliers for any
category you select — complete with direct website links and links to open a "trade account".
Powered by the Claude API + live web search.

---

## 🚀 How to deploy (same workflow as your forge SEO tool)

Same process — the only difference this time is that you do **not** put the API key in the code.
You add it in Vercel's settings instead.

### Step 1 — Upload to GitHub
1. Go to https://github.com → click **New repository** (name it `wholesale-finder`)
2. Upload all the files in this folder (drag & drop works too)
3. Commit the changes

### Step 2 — Import into Vercel
1. Go to https://vercel.com and log in (with GitHub)
2. Click **Add New → Project** → select your `wholesale-finder` repo
3. Click **Import** (no need to change settings — the defaults are fine)

### Step 3 — Add your API key (the most important step)
Before deploying, in the **Environment Variables** section, add:

| Name                  | Value                            |
|-----------------------|----------------------------------|
| `ANTHROPIC_API_KEY`   | `sk-ant-...` (your Claude key)    |

> You can use the same `$5` key you already have. After adding it, click **Deploy**.

### Step 4 — You get a public link 🎉
Once deployed, Vercel gives you a public link such as:
```
https://wholesale-finder.vercel.app
```
Send this link to your team — everyone can use it. Share the same link on LinkedIn.

## 👥 How your team uses it
- Open the link
- Select a category (or type a custom one)
- Click **"Discover distributors"**
- The AI runs a live web search and returns distributors with their wholesale account links

Every search makes a Claude API call (billed to your key), so check your **balance on the
Anthropic dashboard** from time to time: https://console.anthropic.com

---

## 🔒 Never put the API key on GitHub
- A `.gitignore` is already included so `.env` files are never uploaded
- Keep the key only in **Vercel → Settings → Environment Variables**
- If the key is ever exposed by accident, revoke it on the Anthropic dashboard and create a new one
